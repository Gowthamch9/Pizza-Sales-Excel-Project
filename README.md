# 🍕 Pizza Sales Excel Project  

This project analyzes pizza sales data to uncover key insights about customer behavior, product performance, and overall business trends. The goal was to transform raw sales data into **actionable insights** using **SQL, Excel, and interactive dashboards**.  

---

## 📂 Repository Structure  

- **`SQL_Queries/`** → Contains SQL scripts for extracting and preparing the sales data.  
- **`Excel workbook`** → Excel workbook with data cleaning, pivot tables, and dashboard.  
- **`Dashboard/`** → Screenshots of dashboards and key visualizations.  

---

## 🛠️ Skills & Tools Demonstrated  

- **SQL** → Writing queries to extract, filter, and aggregate sales data.  
- **Excel** → Data cleaning, transformation, and advanced analysis.  
- **Pivot Tables & Charts** → Summarizing sales by product, category, and time period.  
- **Interactive Dashboard** → Built in Excel using slicers, filters, and custom charts.  

---

## 📊 Business Questions Answered  

- What are the **best-selling pizzas** by revenue and quantity?  
- Which **categories and sizes** contribute the most to total sales?  
- What are the **peak order times** (daily/weekly trends)?  
- Which **products underperform** and may need marketing changes?
